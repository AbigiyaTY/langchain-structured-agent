# LangChain Structured Research Agent

> An autonomous AI research assistant built with LangChain, Azure AI Foundry, and Pydantic. The agent executes web and Wikipedia searches, logs tools used, and saves strictly validated structured research summaries with timestamps to disk.

---

## 🚀 Key Features

* **Structured Output Generation**: Uses Pydantic schemas (`ResearchResponse`) to guarantee typed JSON responses containing topics, summaries, sources, and execution logs.
* **Autonomous Tool Calling**: Equipped with custom LangChain tools for multi-source search, Wikipedia lookup, and file I/O operations.
* **Azure AI Foundry Integration**: Configured to interface with Azure AI Foundry project endpoints via the standardized OpenAI v1 API route.
* **Persistent Output Logging**: Automatically appends research findings and execution timestamps to `research_output.txt`.

---

## 🚦 Getting Started

Follow these steps to set up and run the research agent on your local machine.

### Prerequisites

* **Python**: Version `3.10` or higher installed.
* **Azure AI Foundry**: Active Azure AI project with an API key, project endpoint, and model deployment `gpt-5-mini`.
* **Git**: Installed on your system.

---

### Installation & Setup

1. **Clone the repository**
```bash
git clone https://github.com/AbigiyaTY/langchain-structured-agent.git
cd langchain-structured-agent

```


2. **Set up a virtual environment**
* **macOS/Linux**:
```bash
python3 -m venv venv
source venv/bin/activate

```


* **Windows**:
```bash
python -m venv venv
.\venv\Scripts\activate

```




3. **Install dependencies**
```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

```


4. **Configure Environment Variables**
Create a `.env` file in the root directory:
```env
AZURE_AI_API_KEY=your_azure_ai_api_key
AZURE_AI_PROJECT_ENDPOINT=https://your-project-name.services.ai.azure.com
AZURE_AI_MODEL=gpt-5-mini

```



---

### 💻 Running the Agent

Execute the main script:

```bash
python main.py

```

Upon execution, the agent will:

1. Research the requested query using available tools.
2. Invoke `save_tool` to write formatted results into `research_output.txt`.
3. Parse and print the validated `ResearchResponse` model directly to your terminal console.
